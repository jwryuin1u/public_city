## A. 작업 전 지적 사항 (원본 가이드라인 중 공도복에 그대로 쓰면 틀리는 부분)

| # | 원본 항목 | 문제 | 적용판 처리 |
|---|---|---|---|
| A1 | 4-1 "현물보상액 ≈ 공시지가 × 1.3~1.7" | 다세대는 **공시지가(토지)** 가 아니라 **공동주택가격(공시가)** 로 비교하는 게 맞고, 증산4 실사례도 공동주택가격 × 1.6. 기준을 섞으면 배수 민감도(1.3/1.5/1.7)가 다른 뜻이 됨 | 다세대: 공동주택가격 × 배수(1.4/1.6/1.8, 증산4 사례 1.6) + 대지지분 × 평당가(4,170만) 교차검증. 단독·토지: 공시지가 배수 유지 |
| A2 | 4-2 "우선공급가 ≈ 인근 시세 70~80%" | 비율 가정보다 **실제 인접 사례 숫자**(증산4: 59 9.55 / 74 10.19 / 84 11.3)가 있음. 사용자 완공시세 기준 59는 71%, 74는 70%로 범위 안이라 모순은 없음 | 증산4 숫자를 기준값으로, 민감도는 "분양가 ±10%" 계수로 |
| A3 | 4-3 "기준일 이후 취득 = 현금청산" | **2025.8.1 시행 개정법**으로 예외가 생김: 기준일 이후라도 ① 해당 물건 최초 거래 ② 매수자 무주택(입주까지 유지) ③ 승계 1회 한정 ④ 법인 제외. 사용자가 **생애최초 무주택**이라 예외 후보 → 단순 "현금청산" 단정이 과도 | 판단표에 `취득일/기준일` + `예외 요건 충족?` 붉은 칸 2개. 요건 미확인 매물은 우선공급 행과 **현금청산 행을 모두** 생성. 단, 2021.6.29 이전 발표 사업지는 기준일 2021.6.29 유지 (불광근린공원 캡처상 기준일 21.06.29) |
| A4 | 1 "완공 시세 15억 초과분은 대출 상한 4억" | 대출 상한은 구간별(15억 이하 6억 / 15~25억 4억 / 25억 초과 2억)이므로 15억 이하도 6억 캡이 있음. 현재 완공시세 13.5~14.5면 LTV 40% = 5.4~5.8 < 6 이라 실효 없음 | LTV 한도 = MIN(시세×40%, 구간 상한). 가정 시트에 구간 입력 |
| A5 | 3-1 "분담금은 완공 시 전액 납부" | 공공분양은 통상 **계약금(계약 시) → 중도금 → 잔금(입주)** 분납. 완공 시 전액 가정은 현금흐름을 낙관적으로 만듦(중도금 이자·중도금 대출 여부) | v0.1은 원본과 동일하게 완공 시 전액(비교 가능성 유지). 분납 비율은 **미확인** → 가정 시트에 메모, 확인되면 현금흐름 이벤트로 분리 |
| A6 | 3-1 "이주비 대출 = 권리가액 × 60% 무이자" | 공공 시행이라 조합 이주비 없음. 토지보상법상 주거이전비·이사비는 소유자 **실거주자**에 한정, 금액도 작음. 세입자 보증금 반환 재원이 사라짐 | 이주 지원 = **0 (미확인)**. 보증금 반환은 저축 + 마통. 이주비 열은 이름 유지, 메모로 "공공 이주지원(미확인 0)" |
| A7 | 3-3 사업성 블록(bottom-up) | 공공이 손익 흡수 → 공사비·일반분양가가 토지주 분담금에 직접 연결되지 않음 | **공급 구조 표**로 대체(4-8). 단, "총공급÷소유자" 비율은 우선공급가 협상력 참고 지표로 유지 |
| A8 | 4-4 전매제한·실거주 의무 | 지구별 미확인. 사용자 시나리오(입주 후 전세 놓기 등)와 충돌 가능 | 가정 시트에 "전매제한 N년 / 실거주 N년 (미확인, 가정 3년)". 판단표에 `처분 가능 시점` 열 추가 (= 완공연도 + 전매제한) |
| A9 | 4-4 "사업계획승인 전까지 소유 유지" | 2025 개정 후 승계 1회 허용과 관계 정리 필요. 승계 요건 충족 매수자는 사업계획승인 후 6개월 내 등 시한 언급 있음(보도) | 붉은 칸 메모로 "시한 미확인". 담당자 질문 리스트에 포함 |

| A11 | 원본 템플릿 '보유현금 산출' 시트 | 현금흐름 시트의 **고정 셀 주소**(H42, H222 …)를 참조 → 행 추가 시 깨짐 | 생성 스크립트가 블록 위치를 계산해 참조 생성. 수동 편집 시엔 같은 제약 있음 |
