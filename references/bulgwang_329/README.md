## 개요 (18.png)
- 유형: **역세권(주거상업고밀지구)** — 역 승강장 반경 350m, 노후도 20년 이상 60%
- 자치구 은평구, 면적 **48,859㎡**, 위치 불광동 329-32 일원
- 용도지역: 기존 제2종(7층)·제3종 일반주거 → 변경 **제3종 일반·준주거**
- 연면적 163,300㎡, 용적률 **386%**, 건폐율 24%, 34층 이하
- 공급 **1,670세대** = 분양 1,386 + 임대 284 (임대비율 17%)
- 단계: **복합지구 지정 단계**, 시공사 선정 준비 중(삼성·롯데·푸르지오 참여 의사). 2026.9 1차 선정 → 12월 총회 최종 결의 예정
- 공공 주관, 시공은 민간. 일반 도시정비법이 아닌 특별법(공공주택특별법) 적용
- 블로그 주장: "착공 3개월 전후 분양계약 후 전매 가능" → **확인 필요** (분양가상한제 전매제한과 충돌 가능)

## 승계 (19.png)
- 조합원(=토지등소유자 우선공급) 지위 승계 가능 매물이 거의 잠긴 상태
- 매수 절차: ① 승계 가능 여부 확인 → ② **LH 공식 검증 (약 45일)** → ③ '승계 가능' 확인 후 계약

## 파생 지표
