## 텍스트 정리 (원문 기준)

### 사업 개요 (04.png)
- 면적: 166,531.2㎡
- 건축규모: 지하 6층 / 지상 42층
- 현 토지등소유자: 655명
- 공급 세대수: 3,568세대 (분양 3,138호, 임대 430호)
- 용적률: 평균 300%
  - 1블럭 261% – 2,465세대
  - 2블럭 403.25% – 1,039세대
  - 3블럭 499.6% – 64세대
- 블로그 해석: 소유자 655명 → 분양 3,138호, "기존 소유주 대비 3.79배 증가"
  (※ 3,138 / 655 = 4.79배 → '379% 증가'의 의미로 보임)

### 블로그 핵심 논지 (01~03.png)
- 공도복은 종전자산가치에 **비례율을 곱하지 않음** → 내 자산의 **감정평가액**으로 수용
- 따라서 개발이익이 소유자에게 돌아가려면, 소유자 분양가(우선공급가)가 일반분양가보다 **월등히 저렴**해야 함
- 증산4의 보상(우선공급)가 수준이 향후 공도복 사업 전반의 성패를 좌우할 것

### 증산5구역 비교 (06.png) — 바로 옆 민간 재개발, 2023년 관리처분인가
- 블로그 표현: 조합원 분양가 59타입 6억원선, 84타입 7억 중반 (평당 1,700~1,900만)
- 기사(하우징워치 2023.04.24, 재분양 신청 시점 '추정' 분양가):
  58A 4.79억 / 58B 4.87억 / 58C 4.88억 / 84A 6.29억 / 84B 6.2억 / 102A 7.16억 / 102B 7.11억 / 102C 7.09억
  - ※ 기사 수치(84 ≈ 6.2~6.3억)와 블로그 수치(84 7억 중반)가 다름 → **블로그 수치(2026.09 작성, 최신 기준)를 채택**
- 비례율 99.94%, 조합원 871명(토지등소유자 975명), 공급 1,704세대
- 블로그 결론: 3년 전 관처 기준이라 해도 증산4 현물보상가는 결코 저렴하다고 할 수 없음

### 증산4 빌라 실사례 (08.png)
- 1991 준공, 전용 11평(1층), 대지지분 26.2㎡(7.9평)
- 2026 공동주택가격 2.06억 → **보상가(감정평가) 3.3억**
- 84타입(11.3억) 분양 시 추가분담금 ≈ **8억**
- 감정평가액 / 공동주택가격 ≈ **1.6배**, 대지지분 평당 ≈ **4,170만**

### 증산5 빌라에 같은 기준 적용 (09~10.png)
- 1993 준공, 전용 12평, 대지지분 5.55평, 2026 공동주택가격 2.59억
- 대지지분 기준: 5.55평 × 4,170만 = 2.31억 → 비례율 99% → 2.28억
- 공시가 기준: 2.59억 × 1.6 = 4.14억 → 비례율 99% → 4.09억
- 84 조합원 분양가 7억 중반 → 추가분담금: 대지지분 기준 5억 초반, 공시가 기준 3억 중반
- (블로그 단서: 감정평가는 실제로 공시가나 대지지분만으로 하지 않음, 비교용 계산)

### 증산4 vs 증산5 결론 (11~12.png)
- 증산5: 토지등소유자 975명(조합원 871명), 공급 1,704세대 = 조합원+일반분양 1,412 / 임대 292
  → 분양호수 ÷ 조합원 = 1.62배 (증산4는 4.79배) → 사업성 자체는 증산4가 월등
- 그런데도 조합원 분양가·추가분담금을 비교하면 **증산5 소유자에게 돌아가는 개발이익이 더 많아 보임**
- 단서: 두 구역 모두 조합원(우선공급) 분양가 미확정. 증산5는 2023 관처 기준
- 증산4 84 우선공급가 11억 이상 — **주민협의체에서 현물보상가 협의 중이라 변경 가능**
- 증산5는 추가분담금 3억 중반, 입주 시점에 분양가가 올라도 증산4보다 많지는 않을 것
