# 도심복합사업 개발이익 귀속 구조 — 웹 검색 메모 (2026.11 검색, 기사·보고서 요약)

사용자 질문 "LH는 수익을 남기지 않는 구조 아닌가?"에 대한 확인. 원문 사이트(dnews, etoday, jaturi) 접속은 세션 네트워크 제한으로 불가 → 검색 요약 기준.

## 확인된 내용
1. **LH 사업수익은 설계상 0.** 공공재개발은 주민이 총사업비 3% 수준 사업시행수수료를 내지만, 도심복합은 공공주택특별법상 LH 자체사업이라 이 수익도 없음. (대한경제 2025.12 시리즈 ②)
2. **개발이익 사용처**: 토지주 추가수익(분양가 할인), 생활SOC, 특수상황 토지주 보호, 세입자 이주대책. 공공시행자는 별도 개발이익 수혜 없음. (국토부/서울대 2023 보고서, 금천구청 안내)
3. **할인 방식**: LH는 "개발이익이 남는 만큼 일반분양가 대비 원주민 분양가 비율을 낮춤" → 우선공급가 = 일반분양가 × (1 − 할인율), 할인율은 사업손익이 0이 되는 수준. (대한경제)
4. **사업비 상승의 전가**: LH 관계자 — 일반분양가는 사업비와 별개로 시세 기반 산정, 사업비 상향분은 주민 할인율에 일부 영향. 분담금 확정 후의 공사비 급등은 LH가 추가분담금 없이 떠안음 → 손실 가능. (대한경제)
5. 6차 후보지 국토부 분석(2021): 우선분양가 시세 대비 평균 60%, 토지주 수익률 민간 대비 +20.0%p. (이투데이) — 초기 전망치.
6. 2023 보고서: "토지등소유자 확정수익률 보장(10~30%p)도 버거운 상황" — 재원 부족.
7. 모든 사업지에서 토지등소유자 분담금 미확정(증산4 포함). 연신내는 2025.5 사업비 16% 증액 후 시공사 선정. 부천 원미는 일반분양가 < 조합원분양가 역전으로 재산정.

## 모델에의 함의
- 이전 설명("남는 돈이 LH에 남는다")은 **틀림** → 남는 돈은 할인율·SOC·이주대책으로 감. 단, 토지주에게 "비례율처럼 자동으로" 오지 않고 LH 산정 할인율을 통해 옴.
- 우선공급가는 사업성과 무관하지 않음: 우선공급가 = 일반 공공분양가(상한제) × (1 − 할인율). 사업성이 나쁘면 할인율 ↓.
- 불광근린공원(총공급÷소유자 1.48, 1종 32%)은 증산4(5.45)보다 할인 여력이 작을 가능성 → 증산4 59 9.55를 그대로 쓰는 현재 가정은 **낙관 쪽**일 수 있음.
- 분담금 확정 후 공사비 상승 리스크는 LH 부담 (모델의 "확정 후 고정" 가정과 일치).
