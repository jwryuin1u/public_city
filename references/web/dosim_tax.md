# 도심복합사업 세법 쟁점 — 웹 검색 메모 (2026.11.12)

## 확인된 내용
- **현물선납은 양도로 보지 않음 (과세이연)**: LH 현물보상 공고 — "현물로 보상받기 위해 공사에 유보하는 현물선납액의 경우 공공주택특별법 제40조의10 등에 따라 양도로 보지 아니하여 과세이연". 세무 칼럼 — 법령 개정으로 공공주택특별법상 현물보상 건축물·토지를 도시개발법상 환지로 봄. 2023.4.18 공포·시행(2차 자료).
- 현물선납액이 분양가를 넘으면 초과분은 현금 수령(그 부분은 양도). 완공 후 주택을 팔 때 양도세 과세.
- 근거는 조특법 제77조의3이 아님(그 조문은 개발제한구역 매수대상 토지).

## 미해결
- 현물보상을 받을 권리가 소득세법상 입주권·분양권·기타 권리 중 무엇인지, 취득시기를 언제로 볼지 명문 규정·유권해석 미비 (세무 칼럼 지적).
- 신축주택 양도 시 종전주택 보유·거주기간 통산 여부에 대한 도심복합 전용 유권해석은 검색되지 않음. 재건축은 보유기간 통산, 공사기간은 거주기간 불산입이 기존 해석.
- → 완공 후 매도 시 1세대1주택 비과세(2년 보유·거주) 충족 여부는 세무사 확인 필요.

## 실거주 요건의 구분
- 공공주택특별법·주택법상 거주의무(분양가상한제 주택 등): 도심복합 우선공급 주택은 해당 없음(보도 기준).
- 소득세법상 1세대1주택 비과세 거주요건(조정대상지역 취득 시 2년): 별개 법. 비과세를 받으려면 필요. 종전주택 거주(2027~29, 3년) 통산이 인정되면 충족, 불인정이면 신축 입주 후 2년 거주 필요.
