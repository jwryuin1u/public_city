# HUG 도심공공주택복합사업대출보증 — 웹 검색 메모 (2026.11.17)

사용자 제공 링크(khug.or.kr 모바일 페이지)는 세션 네트워크 제한으로 열지 못함. HUG 공식 상품 페이지의 검색 요약 기준.

| 보증 종류 | 한도 | 기준 서류 |
|---|---|---|
| 이주비대출보증 | 토지등소유자 **현물선납액의 70% 이내** (현물선납액 = 종전자산 보상총액 − 현금지급액) | 현물선납약정서 |
| 부담금(분담금)대출보증 | 토지등소유자 **부담금의 70% 이내** | 분양계약서 |
| 사업비대출보증 | 단위사업 총사업비의 50% 이내 | 복합사업계획승인서 |

- 신청: 복합사업계획승인 이후. 사업시행자가 집단취급승인 신청 → 승인 후 토지등소유자가 개별 신청.
- 보증기간: 보증부 대출 실행일 ~ 상환기일. 입주 시 상환·전환 조건은 미확인.
- 보증은 은행 대출을 위한 담보 역할. 대출 가능액은 은행 심사와 대출 규제(DSR, 수도권 한도) 적용 여부에 따라 달라질 수 있음 — 미확인.
- 참고: LH 신길2 이주비대출기관 선정 안내문(2026.3) — 대상은 현물선납한 현물보상 대상자, 한도 현물선납액의 70%. 종전자산 추정 평가액 약 5,275억, 이주비 최대 약 3,692억.
- 비교: 일반 정비사업자금대출보증도 이주비 = 종전자산 평가액 70%, 부담금 70%, 사업비 50%(2026.12까지 60%).
