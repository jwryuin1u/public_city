# 증산4구역 웹 검색 메모 (2026.11 검색, 사용자 허가)

## 용적률·인센티브
- 정부가 **종상향 등을 적용해 평균 용적률 295%까지 허용**. 민간 자력 개발 시 247% 대비 +48%p. (파이낸셜뉴스 2024.12)
- 2024.08 서울시 통합심의 조건부 가결안: 지하 5층~지상 41층, 38개 동, 3,568세대, 용적률 상한 300% 이하(평균 294.4~296.33%로 보도마다 상이).
- 구성: 공공분양 2,422 + 이익공유형 716 + 공공임대 430.
- LH 설계안은 허용치보다 낮은 평균 280%, 중심부 저층 → 주민 반발·재설계 요구.
- → **개정 전(1.2배 수준) 인센티브**. 2026.04 개정(1.4배 확대) 적용 여부는 검색에서 확인 안 됨. 사업계획 단계상 미적용 가능성 높음(추정).
- 시공: DL이앤씨·삼성물산 컨소시엄(공사비 약 2조). 당초 일정: 2024 말 사업계획승인, 2026 착공.

## LH 초기 추정치 (2021, 본지구 지정 전)
- 일반분양가 평당 2,257만: 59 5.83억 / 84 7.31억 (분양가상한제)
- **우선공급가 = 일반분양가의 85%** (할인율 15%) → 59 약 4.95 / 84 약 6.21
- 가구당 평균 분담금 **9,000만원**(총 1,665억), 자력 개발 시 2.3억
- 단서: 구역지정 전 추정, 사업시행인가 시점 감정가로 재산정 가능

- 5년 사이 우선공급가가 약 2배. 초기 LH 추정치는 매우 낙관적이었음.
- 2026 기준 할인율이 여전히 15%라면 증산4 59 일반분양가 ≈ 11.2억 (역산). 미확인.

## 불광 모델에의 함의
- 불광근린공원 캡처 16(초기 공급계획)과 같은 **초기 자료의 분양가·분담금 추정은 신뢰 금지** — 증산4에서 2배 괴리.
- 현재 모델의 59 우선공급가 9.55(2026 증산4) × 2030까지 3% 상승 = 10.75는 "증산4 궤적"을 그대로 따른다는 가정. 불광의 사업성 열위(할인율 ↓ 가능)와 1.4배 특례(할인율 ↑ 가능)가 상쇄 요인.
- 증산4 할인율 15%(초기 계획)를 벤치마크로 모델 구조 "일반분양가 × (1 − 할인율)" 적용 가능.
